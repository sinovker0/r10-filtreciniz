# R10 Filtreciniz
R10.net için ücretsiz, açık kaynak Chrome eklentisi. Seçilen kullanıcıların konu başlıklarını ve post mesajlarını yalnızca sizin tarayıcınızda gizler.
## Özellikler
- Konu ve post filtrelerini ayrı ayrı açıp kapatma
- Gizlenen ve taranan içerik sayacı
- Ağ isteği ve sunucu tarafında silme yoktur
- Chrome Manifest V3
## Kurulum
`chrome://extensions` adresini açın, Geliştirici modunu etkinleştirin ve ZIP içeriğini paketlenmemiş öğe olarak yükleyin.
